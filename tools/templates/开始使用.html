SHI ZAI REN WEI · WINDOWS LOCAL APPLICATION

把完整方案带到你的电脑

应用分发整理版 r4 · 2026-10-14；软件 API 版本 v0.6.2。先体验 Python 测算与固定假设方案，再按需配置自己的 API，建立真实 RAG 并生成新 PDF。

先明确你下载的是什么

这是源码型本地应用包，需要 Windows 64 位 Python 3.12，首次联网安装依赖；不是免安装 EXE，不是已经部署的公网服务。没有团队密钥、原机向量库、私人账单或签章。默认只监听本机。

01 · 不花 API 费用，先看产品

  1. 右键 ZIP → 全部解压，放入自己的可写目录。不要在 ZIP 预览中启动。
  2. 准备 Python 3.12（64 位）。安装方法见完整教程。
  3. 双击 start-app.bat，首次等待依赖安装。
  4. 保持启动窗口打开，看到 Open http://… in your browser 后打开该地址。默认 http://127.0.0.1:8000/。
  5. 载入“假设情景演示”并计算，查看比选、敏感性分析及 Python 结果。
  6. 点击“下载青禾示范方案 PDF”。它是固定假设案例，不随输入改变。

不要直接双击 index.html；file:// 页面不表示后端已启动。依赖安装失败时也不表示应用已启动。

02 · 配自己的账号，生成新方案

  1. 双击 configure-keys.bat，填写自己的 DeepSeek、百炼 Key 和对应空间 Base URL。
  2. Key 只保存到本机 backend/.env。不要分享、截图或提交到 Git。
  3. 完全停止自己启动的旧服务，再重启；仅刷新网页不够。
  4. 按完整教程做连接检查及离线资料预检。
  5. 确认授权和费用后，显式选取三份公开资料真实入库；入库后重启。
  6. 核对真实 rag_chunks > 0，完成计算输入后生成新 PDF。

百炼使用自己的 https://…/compatible-mode/v1，不是 /api/v1 或 /embeddings。Chroma 随依赖安装，不需要额外云数据库或 GPU。

遇到启动问题

在应用根目录的地址栏输入 powershell 后回车，可按需要执行以下命令。Python 路径须换成自己电脑上的真实路径。

powershell -NoProfile -ExecutionPolicy Bypass -File .\start-app.ps1 -Port 18061
powershell -NoProfile -ExecutionPolicy Bypass -File .\start-app.ps1 -PythonPath "C:\你的Python目录\python.exe" -Port 18061
powershell -NoProfile -ExecutionPolicy Bypass -File .\start-app.ps1 -IndexUrl https://mirrors.zju.edu.cn/pypi/web/simple -Port 18061

选择 -Port 18061 时打开 http://127.0.0.1:18061/，以窗口实际显示为准。端口占用时选其他空闲端口，不要停止其他项目服务；镜像参数仅本次有效，不更改全局 pip 设置。

体验与工程结论之间的边界

  • 无 Key、无向量库时，新智能方案和 RAG 不会假装成功；本地测算与固定示范 PDF 仍能使用。
  • 青禾是假设案例，不能视作望月公寓真实收益。真实项目需补齐账单、报价、工程量、节能依据与授权。
  • 三份公开资料只是小型流程演示库，不是充分的住宅改造依据，也不包含固定青禾示范 PDF 历史引用的全部标准。新结果不保证与固定 PDF 相同。
  • 其他电脑不能访问你的 127.0.0.1 地址，应各自下载运行。公网部署另需鉴权、HTTPS、配额与数据保护。
  • 本包不含开发测试和 Docker 文件；开发和二次修改请下载完整源码。
