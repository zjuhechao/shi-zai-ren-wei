# 源码副本的数据与材料收集说明

源码副本提供 `data/templates` 下的空白字段模板，CSV 使用 UTF-8 编码并保留第一行字段名，JSON 未知数值保持 `null`。`data/cases/wangyue_case.json` 逐项列出真实案例尚缺的账单、工程量、节能量依据、报价、来源与授权，以及可接受文件格式。

完整的 Word 收集清单和赛事补件模板随上一级“校赛非视频提交包”另行交付，请从该包导航查找。源码只附三份公开政府归档，未附私人项目原件。

- 基线：连续十二个月脱敏账单 PDF/JPG，加每月一行的电量、电费、用户类别与计费口径 CSV。
- 工程量：竣工或测绘 PDF、工程量 XLSX；列明项目、单位、数量、图号、计算过程和复核人。
- 节能量：经复核的节能审计或模型计算书 PDF/XLSX；列明基线、输入、边界、版本、计算方法和输出。
- 报价：供应商 PDF/XLSX，列明规格、数量、单价、安装、税费、质保和有效期。
- 光伏：屋面布置和结构复核、消防及并网意见 PDF，附来源与日期。
- 照片：授权脱敏 JPG/PNG，加逐张来源、授权、处理和复核信息 CSV/XLSX。

未知值留空，数值保留单位、地区、日期、来源。公开信息价和政策不自动替代本项目报价、节能量或补贴资格；加入新 RAG 资料时须更新 manifest 和审核字节指纹，并确认云端处理权限。
