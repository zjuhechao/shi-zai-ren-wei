# 室在人为下载后运行与配置教程

适用于从 GitHub 下载 v0.6.1 源码的评审、同学和演示用户。先运行不收费的本地测算和固定示范 PDF，再按需配置自己的云端账号，建立知识库并生成新方案。源码不含团队的密钥或原机向量库；“下载后可运行”不等于无需 Python、网络或自己的 API 账号。

本版在 Windows x64、Python 3.12.14 的全新独立环境完成了无密钥运行验收。其他 Python 小版本、另一台电脑、Linux、macOS 或 Docker 均需按下列检查确认，不将本机测试视为所有设备的保证。

## 一 获取并解压源码

1. 当前 [zjuhechao/shi-zai-ren-wei](https://github.com/zjuhechao/shi-zai-ren-wei) 是公开仓库，可直接下载，不需要邀请。若以后改为私有，则只对获得权限的账号开放：请持有人邀请你的账号并先接受邀请。收到 404 时先核对地址、账号和当时权限，不需要向持有人索取密码或访问令牌。
2. 打开仓库，在 **Code → Download ZIP** 下载。ZIP 下载方式不需要安装 Git。
3. 右键 ZIP，选择“全部解压”。进入同时包含 `启动演示.bat`、`启动演示.ps1`、`index.html`、`backend`、`assets`、`数据收集包` 的项目根目录。可放到自己的可写文件夹，例如 `D:\Projects\shi-zai-ren-wei`。
4. 不要在 ZIP 的预览窗口中启动，也不要只复制网页三个文件。不要直接双击 `index.html`：`file://` 网页不等于本地后端已启动，不能据此判断 API、RAG 或 Python 测算可用。

## 二 准备 Python

已有 Windows x64 的 Python 3.12 可以直接进入第三步。启动器支持 Python 3.11 及以上，但 Windows 3.12 使用本版完整锁文件，其他版本仅使用直接依赖文件，兼容性需自行验收。Node.js 只用于前端测试，日常运行网页不需要安装 Node.js。Chroma 随 Python 依赖安装，默认保存在本机 `storage/chroma`；不需要 Chroma 云账号、额外数据库服务器或 GPU。

以下两种安装方式任选一种，不要同时安装后再盲目修改系统配置。

### 方式 A 使用 Python 官方安装管理器

Windows 10 或 11 用户可从 [Python 官方下载页](https://www.python.org/downloads/) 获取 **Python Install Manager**，或按该页进入 Microsoft Store 安装。安装后重新打开终端，在任意目录执行：

```powershell
py list --online 3.12
py install 3.12
py -3.12 --version
py -3.12 -c "import struct; print(struct.calcsize('P') * 8)"
```

最后两行应显示 `Python 3.12.x` 和 `64`。`py list --online` 列出的才是该管理器当前可下载的版本。Python 3.12.14 仅提供官方源代码发布，传统官方 Windows 二进制安装器最后一版为 3.12.10；不要把旧版称作最新安全版本，也不要下载不明来源的“3.12.14 官方 EXE”。如需安全维护版运行时，可考虑方式 B。[Python 3.12.14 官方发布说明](https://www.python.org/downloads/release/python-31214/)

若 `py list` 提示无法识别命令，可能已有旧 Python Launcher 占用了 `py`。官方提供无歧义的 `pymanager` 命令，可改用：

```powershell
pymanager list --online 3.12
pymanager install 3.12
pymanager exec -V:3.12 --version
pymanager exec -V:3.12 -c "import sys; print(sys.executable)"
```

把最后显示的 `python.exe` 路径用于第三步的 `-PythonPath`。不需要为了本项目自动卸载旧 Python 或旧 Launcher。若传统安装器提供 **Add python.exe to PATH** 选项，可勾选；安装管理器的命令别名和 PATH 按 [Python Windows 官方说明](https://docs.python.org/3/using/windows.html) 设置，修改后需重新打开终端。

### 方式 B 使用 Astral uv 获取维护版运行时

`uv` 可安装 Astral 维护的 `python-build-standalone` 运行时，它不是 python.org 提供的 Windows 二进制安装器。按照 [uv 官方安装说明](https://docs.astral.sh/uv/getting-started/installation/)，在支持 `winget` 的 Windows 终端执行：

```powershell
winget install --id=astral-sh.uv -e
```

安装后重新打开终端，**在已解压的项目根目录**执行：

```powershell
uv python install 3.12
uv venv --python 3.12 --seed .venv
.\.venv\Scripts\python.exe --version
.\.venv\Scripts\python.exe -c "import struct; print(struct.calcsize('P') * 8)"
.\.venv\Scripts\python.exe -m pip --version
```

应得到 Python 3.12.x、64 位及 pip 版本，并有项目内 `.venv`。`--seed` 用于安装启动器所需的 pip，不能省略。随后使用第三步启动器即可；它会复用该环境并安装项目依赖。这一路径见 [uv Python 安装说明](https://docs.astral.sh/uv/guides/install-python/)和 [uv venv 参数](https://docs.astral.sh/uv/reference/cli/#uv-venv)。本版没有另行下载验收安装管理器或 uv，运行时能否下载还取决于你的网络与系统权限。已存在 `.venv` 时不要直接覆盖；先检查其版本，或在一份新解压的源码中操作。

## 三 启动网页并先做无密钥演示

在项目根目录双击 `启动演示.bat`。首次启动需要联网下载 Python 依赖，之后会自动创建本机 `backend/.env`。等待窗口出现 **Open http://… in your browser**，按它显示的地址打开浏览器；默认是 `http://127.0.0.1:8000/`。启动窗口须保持打开。

也可在项目根目录的地址栏输入 `powershell` 并回车，执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\启动演示.ps1
```

常用可选参数如下。引号内的 Python 路径须换成自己电脑上的真实路径：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\启动演示.ps1 -PythonPath "C:\你的Python目录\python.exe" -Port 18061
```

默认从官方 PyPI 下载依赖；若该源无法访问，可以单次指定本版实际安装成功的浙大镜像，不改全局 pip 设置：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\启动演示.ps1 -IndexUrl https://mirrors.zju.edu.cn/pypi/web/simple -Port 18061
```

`-Port 18061` 时打开 `http://127.0.0.1:18061/`。发现已有同类服务占用端口，启动器只报告其地址与版本，不会替你停止它；如果显示的不是本版 v0.6.1，请选择空闲端口运行本副本。批处理退出后的“按任意键继续”不表示服务仍在运行。

网页验收按这个顺序：

1. 展开“技术状态 → 查看服务连接状态与资料维护”，应看到“后端服务：已连接”“确定性计算引擎：Python 已启用”。没有配置 Key 时，智能体与向量服务显示未配置、Chroma 等待向量服务，是正常状态。
2. 点击“载入假设情景演示”，确认覆盖当前未保存输入，检查页面明确标注假设。
3. 点击“校验并生成初步方案报告”，查看比选和敏感性分析，并可导出 JSON 或可阅读报告。假设情景不代表望月公寓真实收益。
4. 在“完整改造方案与分析 PDF”点击“下载青禾示范方案 PDF”。这是随源码提供的固定、已生成并复核过的假设案例 PDF，不收费，也不会随当前表单输入改变。

此时“生成并下载完整方案 PDF”保持不可用是正常的：它用于根据当前输入真实检索和调用模型生成新文件，不能用固定 PDF 冒充。

## 四 配置自己的 DeepSeek 和百炼

生成新智能方案需要两个服务。DeepSeek 负责理解问题、工具调用和定性正文；百炼负责把文本转成语义向量，本地 Chroma 负责存储并检索。两个平台的 Key 不能互换，每位下载者应使用自己有权限且有余额的账号。

### 获取账户配置

DeepSeek 在其开放平台创建新 API Key，本版默认 `deepseek-flash`、Base URL 为 `https://api.deepseek.com`，使用 Responses API；账号模型权限以实际调用为准。[DeepSeek Responses 官方说明](https://api-docs.deepseek.com/guides/responses_api/)；[DeepSeek Codex 接入说明](https://api-docs.deepseek.com/guides/codex)。本项目不是在 Codex 中填写 Key，因此不要照搬 Codex 的配置文件路径。

百炼在相应地域创建或选择业务空间，再创建有模型调用权限的 Key，并复制该空间的 API Host。Key、地域、业务空间和模型权限必须对应；本版教程以华北2（北京）为例。[百炼获取 API Key](https://help.aliyun.com/zh/model-studio/get-api-key)；[百炼地域与接入域名](https://help.aliyun.com/zh/model-studio/regions)。

百炼 API Host 是主机名，不是本项目要求的完整 Base URL。将自己的主机名组成 `https://自己的WorkspaceId.cn-beijing.maas.aliyuncs.com/compatible-mode/v1`。这里必须填写 **OpenAI 兼容接口的 Base URL**，不是原生 DashScope 的 `/api/v1`，也不是最终 `/embeddings` 请求地址。`text-embedding-v4` 本版使用 1024 维、每批最多 10 条，与官方兼容接口一致。[百炼 OpenAI 兼容向量说明](https://help.aliyun.com/zh/model-studio/embedding-interfaces-compatible-with-openai/)；[文本向量 API](https://help.aliyun.com/zh/model-studio/text-embedding-synchronous-api)。

| 本地字段 | 应填写内容 |
| --- | --- |
| `LLM_API_KEY` | 自己的新 DeepSeek API Key |
| `LLM_BASE_URL` | `https://api.deepseek.com`，不要追加 `/responses` |
| `LLM_MODEL` | `deepseek-flash`，须有相应调用权限 |
| `VISION_MODEL` | 默认 `deepseek-flash`；图片能力另行授权和验证 |
| `LLM_REASONING_EFFORT` | 本版默认 `none` |
| `EMBEDDING_API_KEY` | 自己百炼相应地域和业务空间的 Key |
| `EMBEDDING_BASE_URL` | 自己空间的 `https://…/compatible-mode/v1`，不要追加 `/embeddings` |
| `EMBEDDING_MODEL` | `text-embedding-v4` |
| `EMBEDDING_DIMENSIONS` | `1024` |
| `EMBEDDING_BATCH_SIZE` | `10` |

### 在本机保存配置

推荐先完成第三步，再双击 `configure-keys.bat`。已有可用 Python 时，也可以在未安装项目依赖之前配置；该入口会检查虚拟环境、Python Launcher 和 PATH，也支持 `configure-keys.ps1 -PythonPath`。按顺序输入两个隐藏的 Key、百炼 Base URL，最后输入可留空的 DeepSeek Base URL。输入 Key 时不显示字符，回车继续；留空保留已有值，不会清除它。配置工具只写本机文件，不发起 API 调用。

填写新的 DeepSeek Key 时，向导绑定官方 `https://api.deepseek.com` 接口，并选择 `deepseek-flash`，避免把新 Key 发到旧的第三方地址。百炼地址必须完整且以 `/compatible-mode/v1` 结尾；误填原生接口、占位符或第三方地址会阻止保存，不覆盖已有配置。若百炼 Key 已填写但 Base URL 留空，会明确显示 `INCOMPLETE`，补齐之前 RAG 不能使用。保存成功只代表配置格式检查通过，不代表账户有效或云端已联通。

也可以在项目根目录的交互终端直接执行同一个工具：

```powershell
.\.venv\Scripts\python.exe backend\scripts\configure_secrets.py
```

模型等其他字段可用本机文本编辑器调整 `backend/.env`，字段名以 `backend/.env.example` 为准。不要把 Key 作为命令行参数，不要把配置文件发给别人，不要将它放入截图、录屏、压缩包或 Git；Git 已忽略该文件，但手工打包时仍需自行排除。聊天或其他渠道已公开过的 Key 应在对应平台撤销并重新创建，而不是复制给下载者。

保存后**彻底停止原服务，再从新窗口启动**：在自己用于启动项目的窗口按 `Ctrl+C`，等待服务停止并关闭该窗口，然后再次运行 `启动演示.bat`。仅刷新网页不会让已加载的进程重新读取全部配置。不要停止别人的或其他项目的服务。

## 五 检查连接并建立本地知识库

以下命令全部在项目根目录运行；无需手动激活虚拟环境，因为命令直接使用项目内的 Python。

先检查配置是否齐备，不收费、不调用 API：

```powershell
.\.venv\Scripts\python.exe backend\scripts\check_connectivity.py
```

输出应有 `configuration_only: true`、`llm_configured: true`、`embedding_configured: true`。这些只表示字段存在，**不表示 Key 有效或模型已联通**。愿意承担两次小额测试调用时，显式执行：

```powershell
.\.venv\Scripts\python.exe backend\scripts\check_connectivity.py --online
```

测试只发送固定连接测试文字，不发送客户资料或照片。成功时应看到 `llm.status: ok`、`embedding.status: ok`、`embedding.dimensions: 1024`。失败时看 `status`、`error_type`、`http_status`，不要只凭命令结束或退出码判断成功。这项测试不验证工具编排、照片识别或 RAG 答案质量。

接着做本地文档预检，不收费、不上传正文、不生成向量：

```powershell
.\.venv\Scripts\python.exe backend\scripts\ingest_knowledge.py --audit-only
```

干净源码只带三份公开归档；应看到 `parseable_documents: 3`、`blocked_documents: 0`，`planned_chunks` 是计划切分数，不是已入库数。首次本地向量数为 0，原机 22 份资料、482 个片段不能算作下载者已拥有的库。

确认这三份资料可向自己的百炼服务发送，且接受调用费用后，再明确选择文档入库：

```powershell
.\.venv\Scripts\python.exe backend\scripts\ingest_knowledge.py --document-id DOC-FAC-0001 --document-id DOC-POL-0002 --document-id DOC-POL-0004 --reviewed
```

首次成功应有 `indexed_documents: 3`、`collection_count` 大于 0；以实际结果为准。重复执行时，未变的已审核文件可显示在 `unchanged_documents`，不是失败。清单路径、正文解析或审核指纹有问题会阻断或跳过，跳过文件不算已入库。不要修改文件后假装审核指纹仍有效，也不要开启两个进程同时写同一 Chroma 目录。

入库后再彻底停止并重新启动服务，然后刷新网页“技术状态”；应看到模型与向量服务“已配置”、Chroma“已建立”及真实片段数。也可打开当前端口的 `/api/health`，检查 `version`、`rag_ready`、`rag_chunks`；该健康检查本身不调用云端。更换向量模型、维度或 Base URL 会对应另一份索引，必须按新配置重新入库，不能混用旧向量。

## 六 生成自己输入的新方案

1. 载入假设情景，或录入已获授权且带来源、日期的真实项目基线和方案数据，先完成“校验并生成初步方案报告”。缺失数据不要伪填；真实账单、报价、工程量、节能依据和授权不足时保留缺口。
2. 可先在“追问与核查”输入政策问题，检查答案引用的标题与来源；检索片段不是自动适用的工程结论。
3. 在“完整改造方案与分析 PDF”补充项目目标，需要时填写仅改变投资的比较情景，点击“生成并下载完整方案 PDF”。阅读并确认云端处理与费用提示，再等待实际调用。
4. 成功后浏览器下载新 PDF；复核项目名称、输入、假设、数值、来源与缺口。发生错误时系统显示未完成，不会换成固定青禾 PDF 冒充成功。

三份公开样本只是小型流程演示库，不是住宅改造的充分依据，也不包含固定青禾报告曾引用的历史 `DOC-STD-0007` 全文；因此不保证新生成结果与固定 PDF 的引用、章节或文字相同。住宅项目仍需补充适用标准与经授权资料，核对对象、地域、有效性和证据，具体见 [数据与材料收集清单](数据与材料收集清单.md)。新增资料应按清单登记来源并审核，不直接批量上传私人账单、签章或照片。

新生成报告的输入和审计保存在本机 `storage/reports`，本地向量在 `storage/chroma`，不随 Git 共享。照片分析需要另行取得上传授权并验证模型能力；上述连接测试和资料入库没有替你完成照片效果验收。所有方案都是待专业复核的前期方案，不替代施工图、施工许可或正式工程审查。

## 七 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 仓库链接 404 或无法下载 | 登录被邀请的 GitHub 账号并接受邀请，联系持有人确认私有仓库权限。 |
| 双击网页显示后端未启动 | 关闭 `file://` 页面，启动项目，使用窗口显示的 `http://127.0.0.1:端口/`。 |
| `py` 找不到或提示没有 Python | 先验证 Python 3.12；旧 Launcher 冲突可用 `pymanager`，或给启动器 `-PythonPath`。仅存在 WindowsApps 商店占位命令不等于已安装运行时。 |
| 依赖下载超时、安装失败 | 检查网络与 HTTPS 证书，再单次使用上述 `-IndexUrl`。不要关闭证书验证；安装失败时服务器尚未启动。 |
| 端口被占用或页面是旧版本 | 用 `-Port 18061` 或其他空闲端口，再打开对应地址；不要误停其他服务。 |
| 配置后仍显示未配置 | 检查是否写入当前副本的 `backend/.env`，彻底停服后重启；不是只刷新网页。若终端预设了同名环境变量，会优先于 `.env`，请在自己的新终端确认配置来源。 |
| 401 或 403 | 在相应平台检查 Key 是否有效、地域与空间是否匹配、是否有模型权限；不把两家的 Key 互换。 |
| 404 或模型不存在 | 核对 Base URL 协议和路径、模型名称及区域模型列表。百炼不要填 `/api/v1` 或把 `/embeddings` 放入 Base URL。 |
| 429、余额或限流提示 | 到自己的平台检查余额、配额和限流，按提示等待；不要反复批量调用造成费用。 |
| API 显示已配置，但问答仍失败 | 先运行显式在线连接测试并检查结果，再查看知识库、输入与实际错误；已配置不是已验证。 |
| Chroma 尚未入库或 `rag_chunks: 0` | 先离线预检，再按授权显式入库；更换模型、维度或地址后须建立匹配的新索引。 |
| 未检索到资料或 PDF 生成被阻断 | 核对输入地区、文件有效性和样本适用范围，补充合适且获授权的证据；不使用虚构来源或静态答案替代。 |
| 示例 PDF 能下载，但新方案按钮不可用 | 示例是固定资产。新方案需要先计算，且模型、向量服务与非空知识库均就绪。 |
| 中文 PDF 字体报错 | Windows 检查可用的合法中文字体；特殊环境可用 `REPORT_FONT_PATH` 指向中文 TTF/TTC，并重新检查排版。 |
| 诊断命令的中文显示乱码 | 在当前 PowerShell 执行 `$env:PYTHONUTF8 = "1"` 后重试，或使用支持 UTF-8 的终端；这不代表源文件或计算数据已损坏。 |

需要进一步定位时，在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe backend\scripts\check_readiness.py --json
```

`pip check` 应无依赖冲突，准备检查的 `passed` 应为 `true`。后者验证无密钥演示与本地前提，不验证外部 API、资料适用性或照片效果。求助时可提供错误类型、HTTP 状态、Python 版本和已隐藏敏感信息的结果；不要发送 `.env`、Key、私人资料或含身份信息的截图。

默认只监听 `127.0.0.1`，其他电脑不能通过你的本机地址访问；本教程教每位下载者在自己电脑运行。公网部署需要另外实现鉴权、HTTPS、配额和数据保护，不能直接将此本地演示暴露到互联网。
