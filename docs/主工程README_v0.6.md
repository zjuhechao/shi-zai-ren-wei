## 今天直接演示

最短完整流程：载入假设情景 → 修改项目名称与参数 → 校验并生成初步方案报告 → 填写“方案 PDF”的目标及可选比较投资 → 生成并下载完整方案 PDF。该入口会调用云端服务并产生费用。已有青禾成品可点击“下载青禾示范方案 PDF”，不重复调用 API；该固定示例不是当前输入的计算结果。

1. 双击 `启动演示.bat`。首次运行会建立本地环境并安装依赖。
2. 浏览器打开 `http://127.0.0.1:8000`。
3. 点击“加载已核验字段”，系统只填入望月公寓名称、地区和有官方来源的浙江省电力排放因子。
4. 不补造电量、工程量或节能量，直接点击“校验并生成初步方案报告”，展示系统如何列出阻断项。
5. 本机可演示智能体问答与来源返回；新增入库会产生外部 API 调用，须使用审核名单。照片分析只在材料授权、脱敏和人工复核条件满足后演示。

直接双击 `index.html` 可进入离线校验模式，但不会声称使用了 API、RAG 或 Python Tool Calling。

## 完整模式需要的账号

- 智能体与多模态：DeepSeek `deepseek-flash`。在 `backend/.env` 填写新建的 `LLM_API_KEY`；不要使用聊天中暴露过的密钥。
- 语义向量 RAG：DeepSeek 当前没有文本向量接口。推荐阿里云百炼 `text-embedding-v4`，填写 `EMBEDDING_API_KEY`、业务空间对应的 `EMBEDDING_BASE_URL` 和模型名。
- 不想使用第二个平台时，可后续改成本地中文嵌入模型；必须先下载模型并完成离线验收，不能把关键词检索称作向量语义RAG。

配置方法见 `docs/API与平台操作清单.md` 和 `backend/README.md`。所有密钥只保存在本机 `backend/.env`，该文件已被 `.gitignore` 排除。

- 后端健康检查和显式降级，服务失败不会静默伪装为完整模式。
- 完整方案 PDF：现状与目标、措施包、方案比选、确定性测算、现金流与敏感性、采购实施、验收、风险、资料缺口和检索来源。原始输入与生成记录保存在未对网页公开的 `storage/reports`。

## 计算边界

所有结果只用于前期筛查和方案比选。静态回收期为“净投资 ÷ 年度净收益”；年度净收益不大于零时不输出回收期。模型不得从照片、标准限值或知识记忆中补造工程量、传热系数、价格、补贴或节能量。
