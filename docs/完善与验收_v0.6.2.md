在源码根目录、依赖已安装后执行；以下命令不调用云端模型：

```powershell

.\.venv\Scripts\python.exe -S backend/tests/configuration_checks.py -v

node backend/tests/test_client_ui.cjs
node backend/tests/test_case_prefill.cjs
node backend/tests/test_frontend_resilience.cjs
```

Node 仅用于开发回归，不是用户启动应用的运行要求。若当前环境阻止本机测试服务或 asyncio 回环套接字，应在允许本机回环的环境执行，不应把受限执行失败隐藏为成功。

有费用的在线诊断必须另行同意并显式 `--online`；本轮没有运行在线路径，也没有读取或重建原机私有向量库。

## 校赛前最终核查（2026-10-21）

三项 bug 修复与前端体验增强，均已在 `02_本机运行` 与提交源码仓库同步，全部测试通过。

**修复的问题**
1. PDF 有效性标签映射不一致：`retrieval.py` 返回 `within_recorded_interval / outside_recorded_interval / unverified` 三个枚举，但 `plan_pdf.py` 状态表仍查旧键，导致 PDF 泄露内部英文枚举。已对齐，PDF 现显示中文「登记日期区间内 / 区间外 / 待核实」。
2. 照片分析同步阻塞：`/api/vision/analyze` 为 async 路由却同步执行最长 90 秒网络调用，会卡死事件循环。已改为线程池执行，照片分析期间健康检查等其他接口保持响应。
3. 前端双实现漂移风险：新增 `verify_frontend_calc.cjs`，从 `app.js` 真实源码抽取计算函数与 `calculators.py` 逐项断言，守护前后端公式一致性。

**前端客户体验增强**（新增 `charts.js / ux.js / ux.css`，不改变计算口径、不引入本地存储）
- 录入完成度进度条、底部悬浮操作栏、滚动导航高亮、字段级即时校验、操作反馈提示、离开提醒。
- 基线表单拆为三步向导（项目信息 → 用电与电价 → 碳因子与日期）。
- 结果区纯前端 SVG 图表（净投资对比条形图 + 15 年累计现金流曲线）。
- Hero 区渐变光晕、网格线与碳排趋势装饰。

**测试计数更新**
- 后端 unittest：84 → 86 项（新增照片分析线程池回归、前端对齐包装各 1 项）。
- 新增浏览器 E2E：UX 11 项、UI 增强 16 项、UI 视觉 5 项、前端口径 11 项，全部通过。
