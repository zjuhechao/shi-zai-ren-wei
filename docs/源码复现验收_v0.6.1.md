## 报告和技术路线

固定 PDF 的原 API 生成版本为 v0.6.0，时间为 2026-10-12；2026-10-13 是内容复核 r2 纳入 v0.6.1 材料的日期。本轮未重新生成模型正文。新完整智能方案仍需真实百炼向量、Chroma 检索与 DeepSeek API 就绪，不能用固定成品冒充新输入的智能输出。

Python 负责确定性数值，模型撰写定性草案。总投资、节电量和碳因子必须来自明确输入；假设与待核验资料保留性质标签。官方 CO2 参考值不自动替换程序 CO2e 字段，真实望月公寓的收益没有被假设案例替代。

## 未完成的验收

本次是同一机器上的新源码、新独立环境复现，不是另一台电脑部署、Linux/Docker 构建或公网客户服务验收。没有把 53 项单元测试或 20 项 HTTP 检查当成模型准确率、检索准确率或照片识别效果指标。Docker 仅完成配置审查；公网身份认证、HTTPS、配额和费用管理仍需专门实现。

原始申请中自动气候与辐射关联、完整热工模型、预算自动匹配及企业平台插件仍是后续目标，照片接口也需授权样本效果验收。工程量、报价、节能量依据、账单、核算边界、现场设计与授权必须补齐后再开展真实工程决策。
